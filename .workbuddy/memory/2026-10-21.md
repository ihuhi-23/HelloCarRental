# 2026-10-21

## 修复后台 Banner 轮播图预览层级问题
- 文件：`backend/admin/index.html`（单文件 Element Plus 后台，CDN 引入 vue3 + element-plus）
- 原因：表格里的 `<el-image preview-src-list>` 未开启 `preview-teleported`，预览层被挂在表格单元格内部，受表格/弹窗层叠上下文影响，出现预览图被表格行、弹窗遮挡且被裁剪。
- 改动：
  1. Banner 列表缩略图与编辑弹窗内预览图均加上 `preview-teleported`、`hide-on-click-modal`、`initial-index`、`cursor: zoom-in`。
  2. 新增 CSS 兜底：`.el-image-viewer__wrapper { z-index: 3000 !important; position: fixed; inset: 0 }`，canvas 提层；大图限制 `88vw / 86vh` 并加阴影圆角；`.el-table .el-image { display: inline-flex }`。
- 验证：用 puppeteer-core + 本机 Chrome headless 实测（后台 `node backend/server.js`，端口 3000）：预览层 parent 为 body、z-index 3000 > 弹窗 2001、图片位于命中测试最上层；列表与弹窗内预览均正常。

## 回归修复：预览工具栏/关闭按钮点不动
- 原因：上一步给 `.el-image-viewer__canvas` 加了 `position: relative; z-index: 1`，而 Element Plus 的 toolbar / 关闭按钮是与 canvas 同级的绝对定位兄弟节点（DOM 顺序在 canvas 之前），被 canvas 盖住 → 放大、旋转、关闭全部点不到。
- 改法：删除 canvas 的层级设置，改为只给 `.el-image-viewer__actions / __close / __btn / __prev / __next` 提升到 `z-index: 10 !important`。
- 验证（puppeteer 逐个点击）：缩小 1→0.833、放大回 1、rotate-left → matrix(0,-1,1,0)、rotate-right 复原、滚轮缩放 1.2、关闭按钮与点遮罩均能关闭。
- 经验：Element Plus image-viewer 内部层级不要动 canvas，只抬控制按钮。
